# Custom Docker Build Repository

这是一个用于集中管理个人/自用定制化 Docker 镜像构建脚本的 Monorepo 仓库。

> **架构说明**：本仓库**仅负责镜像的打包定义与构建（Build-Only）**，不包含任何运行时数据、日志、持久化卷目录或环境敏感配置文件。运行时配置与数据维护均在生产宿主机的独立目录中管理。
